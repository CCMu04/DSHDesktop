# DSH Dock 品牌说明

## 定位

DSH Dock 是面向 Windows 的独立非官方社区桌面封装。它运行并呈现未经修改的 DeepSeek Harness Web UI，但不属于 DeepSeek 或 DeepSeek Harness 官方产品，也不表示任何官方背书关系。

## 为什么调整品牌

原有名称更接近功能描述，难以区分上游项目与桌面封装本身。`DSH Dock` 表达了产品的核心作用：把 DSH 的 Web 工作界面稳定地“停靠”到桌面应用中，同时保留终端、配置、会话和插件工作流。

新的主标记由开放式终端框、命令提示符和向外延伸的底部轨道组成。它在小尺寸下仍能保持清晰，也比具象吉祥物更直接地传达桌面终端工具属性。

## 为什么不再使用原来的素材

上游鲸鱼标识属于上游项目的品牌表达。继续将其作为本应用主图标或字标，容易让用户误认为 DSH Dock 是官方客户端、官方发行版或获得官方背书，也不利于区分上游软件与社区封装各自的素材边界。

因此，DSH Dock 不再复用上游鲸鱼素材作为产品标识。品牌套件中的辅助鲸鱼是重新绘制的独立单色线条形象，只用于启动页、空状态和宣传场景，不替代主图标，也不用于暗示官方关系。

## 资源与使用范围

- `assets/icon.svg` / `assets/icon.png`：Windows 应用和安装包主图标。
- `assets/brand/mark.svg`：透明背景主标记。
- `assets/brand/wordmark.svg`：浅色背景字标。
- `assets/brand/wordmark-inverse.svg`：深色背景字标。
- `assets/brand/whale.svg`：低权重辅助形象。

主图标应保持黑白配色与现有留白，不叠加鲸鱼、文字或额外装饰。辅助鲸鱼不得单独作为应用图标使用。

## 升级兼容

品牌调整只改变用户可见名称与视觉素材。内部 `appId`、GitHub 仓库地址和安装包文件名前缀继续保留，以维持现有安装识别、覆盖升级和自动更新兼容性。
